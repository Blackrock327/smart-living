วิธีแทนที่เว็บไซต์ Smart Living ใน VS Code
=============================================

ไฟล์ในชุดนี้
- index.html       หน้าเว็บไซต์หลัก
- style.css        สี รูปแบบ และการจัดวาง (ต้องอยู่โฟลเดอร์เดียวกับ index.html)
- script.js        ข้อมูลอุปกรณ์และการโต้ตอบบนหน้าเว็บ
- floor-plan.svg   แปลน 2D แบบคลิกเลือกห้อง

วิธีติดตั้ง
1. แตกไฟล์ชุดนี้ลงในโฟลเดอร์โปรเจกต์เว็บไซต์เดิม หรือสร้างโฟลเดอร์ใหม่
2. หากมีไฟล์ชื่อเดียวกัน ให้สำรองไฟล์เดิมไว้ก่อน แล้วแทนที่ทั้ง 4 ไฟล์ด้วยไฟล์ในชุดนี้
3. เปิดโฟลเดอร์นั้นใน VS Code โดยเลือก File > Open Folder...
4. ตรวจสอบว่าไฟล์ทั้งสี่อยู่ระดับเดียวกัน ไม่ได้อยู่ในโฟลเดอร์ย่อยคนละที่
5. เปิด index.html ด้วยส่วนเสริม Live Server (คลิกขวา > Open with Live Server)
   หากยังไม่มี Live Server ให้เปิดหน้า Extensions ใน VS Code แล้วติดตั้งส่วนเสริม
   ชื่อ Live Server จากผู้พัฒนา Ritwick Dey จากนั้นเปิดหน้าเว็บอีกครั้ง

วิธีลองใช้งาน
1. คลิกห้องใดก็ได้บนแปลน แผงด้านขวาจะแสดงรายการอุปกรณ์ของห้องนั้น
2. คลิกสวิตช์เพื่อเปลี่ยนสถานะตัวอย่างของอุปกรณ์
3. กด "ดูทุกห้อง" เพื่อกลับไปดูจำนวนรวม หรือปุ่มลูกศรวนด้านบนเพื่อคืนสถานะเริ่มต้น
4. ลองย่อหน้าต่างเบราว์เซอร์หรือเปิดบนโทรศัพท์ เพื่อตรวจดูการจัดวางแบบ responsive

ข้อมูลและข้อจำกัด
- แปลน SVG วาดเป็นเส้นเวกเตอร์โดยอ้างอิงตำแหน่งห้อง สัญลักษณ์ เฟอร์นิเจอร์ และมิติจาก PDF
  เส้นบางส่วนเป็นการถอดแบบด้วยมือ ขนาดที่แสดงบนเว็บปรับตามหน้าจอ จึงไม่ควรใช้วัดระยะ
  หรือแทนแบบ CAD/แบบก่อสร้าง
- ตัวเลขมิติ 9.70 และ 12.50 เมตรเป็นตัวเลขที่อ่านได้จาก PDF ส่วนในแบบยังมีมิติด้านอื่น
  ที่ไม่สอดคล้องกัน จึงแสดงเป็นมิติอ้างอิงและไม่ใช้ยืนยันขนาดพื้นที่จริง
- ตัวเลขอุปกรณ์อ้างอิงจากแถวใน XLSX: เครื่องปรับอากาศ 3, หลอดไฟ 13,
  โทรทัศน์ 1, ตู้เย็น 1, เครื่องซักผ้า 2 รวม 20 รายการ
- XLSX มีจำนวนอุปกรณ์แต่ไม่มีวัตต์หรือชั่วโมงใช้งาน เว็บไซต์จึงแสดง kWh/เดือนเป็นค่าประมาณจากสมมติฐานตัวอย่าง ไม่ใช่ค่ามิเตอร์จริง
- แก้กำลังไฟและเวลาใช้งานได้ในส่วน energyModel ช่วงต้นไฟล์ script.js (ค่า watts, hoursPerDay, hoursPerCycle และ cyclesPerMonthPerUnit)
- ข้อความภาษาไทยของชื่อห้องใน XLSX แสดงผลไม่สมบูรณ์ การจับคู่ชื่อห้องใช้ลำดับแถว
  ที่ตรงกับรายการห้องบนแบบบ้าน หากลำดับในไฟล์ต้นฉบับต่างออกไป ให้แก้ข้อมูลใน script.js
- สวิตช์เป็นเพียงการสาธิตสถานะในเบราว์เซอร์และบันทึกไว้ในเครื่องเท่านั้น ไม่ได้เชื่อมต่อ
  หรือสั่งงานอุปกรณ์ Smart Home จริง

ถ้า CSS ยังไม่เปลี่ยน
- ตรวจสอบชื่อให้เป็น style.css (ไม่ใช่ style.css.txt)
- ตรวจสอบว่า style.css อยู่ข้าง index.html ในโฟลเดอร์เดียวกัน
- บันทึกไฟล์ด้วย Ctrl+S แล้วรีโหลดหน้าเว็บแบบล้างแคชด้วย Ctrl+Shift+R
- อย่าเปิดไฟล์ CSS แยก ให้เปิด index.html ผ่าน Live Server
